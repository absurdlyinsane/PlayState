# PlayState
A Web-based media, film, and game tracking system powered by PocketBase and with a UI inspired by Metro design.

## What it Does
PlayState allows users to easily track, rate, and organize their media consumption across various entertainment types including movies, TV shows, and video games. It leverages PocketBase to provide a fast, lightweight, and self-hosted backend solution for managing personal media libraries.

## Who is it for
This system is designed for media enthusiasts, cinephiles, and gamers who want a unified, private, and customizable platform to keep track of their backlogs and completed titles without relying on multiple third-party services.
